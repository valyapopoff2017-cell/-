# Банная мануфактура

Каталог заполнен по документу «Документ Microsoft Word (2).docx», предоставленному заказчиком. В нём 39 моделей в 8 категориях: 16 бань-бочек, 9 квадробочек, 3 «Викинг», 1 «Парус», 2 модульные бани, 1 капсульная, 2 квадроовальные и 5 модульных домов. У 37 моделей указана цена; две модульные бани — по запросу.

## Запуск и просмотр

Зависимостей нет. Откройте index.html прямо в браузере или выполните `npm start` (Node.js 18+) из папки проекта. Сервер использует порт 3000 или PORT.

Ссылки вида `#product/quadro-08` открывают отдельную модель при прямом переходе и перезагрузке. Скопированная ссылка доступна клиенту только после размещения сайта на общедоступном хостинге. Локальные file:// ссылки передавать клиентам нельзя.

## Что работает

Категории, поиск, сортировка, карточки моделей, копирование ссылок, подборка с сохранением в localStorage, сумма известных цен и подготовка запроса менеджеру. Отправки заявок и оплаты нет.

## Данные

catalog.json — исходные данные; catalog.js — те же данные для открытия без сервера. Изображения извлечены из скриншотов без удаления водяных знаков. Разрешение небольшое: для качественных крупных изображений нужны оригиналы. Полная комплектация и шесть размеров предоставлены только для квадробочки «600 VIP»; характеристики других моделей не выдуманы. Данные о наличии «2 шт.» и обещание «Привезём завтра» из примера не используются, поскольку актуальность неизвестна. Старые зачёркнутые цены не используются.

Телефон, мессенджер, адрес и отзывы в документе отсутствуют. Контактная кнопка ведёт на сайт производителя; карта и отзывы явно обозначены как незаполненные. Для публикации подтвердите актуальность цен и добавьте контакты.

## Проверки

`npm test` — полнота каталога, категории, изображения, цены и отдельная комплектация VIP. Браузерные проверки проверяют фильтры, ссылки, подборку, запрос, адаптивность и открытие файла напрямую.

## Премиальное оформление и отдельные страницы

Главная — `index.html`, каталог — `catalog.html`, товар — `product.html?id=quadro-08` (для примера). Карточки из каталога и подборки открываются в новой вкладке; фильтры текущей вкладки сохраняются. Подборка синхронизируется между вкладками через событие localStorage. Старые адреса `#product/...` перенаправляются на новую страницу товара.

Логотип заново оформлен как светлый векторный знак `assets/logo.svg` по присланному образцу. Главный экран использует специально сгенерированное атмосферное изображение `assets/hero.png`: это оформление бренда, а не фотография конкретной модели каталога.

`python3 build-standalone.py` обновляет три страницы из шаблона `tools/build_pages.py` и создаёт `/workspace/bannaya-catalog.html` со встроенными стилями, данными и изображениями. В автономной версии главная, каталог и товар разделены маршрутами `#home`, `#catalog`, `#product/...`; товар также открывается в новой вкладке. Для правок HTML меняйте шаблон, затем пересоберите страницы. Каталог и цены сохранены из документа заказчика.
